# NATB Issue 追踪

> **本仓库不存放任何源码，仅用于收集与追踪 issue。**
> 源码与官网分别在 [natb-website](https://github.com/Mengmiya1027/natb-website) 与 NATB-Cli 主仓库，请不要在这里提交代码。

这里是 [NATB（小天才手表 ADB 工具箱）](https://natb.top) 的问题反馈与功能建议入口。

---

## 两种提交方式

**方式一：在官网里直接发**（推荐）

打开 <https://mengmiya1027.github.io/natb-website/issue> → 点右上角「登录」→ 用 GitHub 账号授权 → 「新建 Issue」。

在站内可以直接看到 issue 列表、详情、评论与时间线，发帖时会自动带上标题与正文格式；登录后也能在站内评论、打标签、关闭 issue。不需要额外注册任何账号。

**方式二：在 GitHub 上发**

直接点 <https://github.com/Mengmiya1027/NATB-Cli-issue/issues/new>，效果完全一样。

---

## 提问前先做两件事

1. **搜一下**：用页面上的搜索框（或 GitHub 的搜索）确认没有人提过同样的问题。重复的 issue 会被合并。
2. **更新到最新版**：很多问题在新版本里已经修好，先确认你用的是最新版本。

## 一个有用的 issue 长什么样

| 部分 | 请写清楚 |
|---|---|
| **设备型号** | 例如 Z6 / Z7 / Z8 / Z9 / Z10 / Z11，RTOS 设备请注明 |
| **系统版本** | 例如 安卓 7.1 / 8.1 / 11，或 RTOS 具体版本 |
| **NATB 版本** | 例如 v1.1.0，在「更新」页能看到 |
| **操作步骤** | 你点了什么、按了什么顺序，越具体越好 |
| **期望结果** | 你以为会发生什么 |
| **实际结果** | 实际发生了什么（报错原文、截图更好） |
| **是否可复现** | 每次都能复现，还是偶发 |

> 报错信息、日志、截图都可以直接拖进编辑框。**贴之前请先打码**：IMEI、序列号、手机号、QQ 号等个人信息不要公开。

## 标签说明

| 标签 | 含义 |
|---|---|
| `bug` | 功能不符合预期，或直接崩溃 |
| `enhancement` | 新功能建议、体验优化 |
| `documentation` | 文档、说明有误或缺失 |
| `duplicate` | 与已有 issue 重复 |
| `good first issue` | 适合第一次参与的问题 |
| `accessibility` | 可读性、对比度、无障碍相关 |

---

## 处理节奏

- 所有 issue 都会有人看，但不保证响应时间。
- 被确认的问题会打上标签并排进里程碑；修好后会在「更新」页与 release 里说明。
- 长期没有进展的 issue 可能会被标记为 `not planned` 后关闭，这**不代表它不重要**，只是当前排期排不进去。随时可以重新打开。

---

## 边界

这个仓库只管**问题反馈与功能建议**。

- 使用教程、常见问题 → 见官网的「功能」与「更新」页
- 源码问题 → 到对应的代码仓库提
- 安全漏洞 → **不要公开提 issue**，请私下联系维护者
